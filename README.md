# Memora27 Releases

Public binary distribution repository for **Memora27**.

- **Windows Desktop (`v*.*.*`)**: NSIS installer (`.exe`), `latest.yml`, `release.json`, and `.blockmap` files.
- **Browser Extension (`ext-v*.*.*` / `extension-latest`)**: Packaged Chrome & Edge extension archives (`memora27-extension.zip`).

Source code is maintained separately in a private repository.

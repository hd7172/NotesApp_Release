# Memora27 – Public Release Repository

Public binary distribution repository for **Memora27**.

This repository contains downloadable application releases only. Source code is maintained separately in a private repository.

### Windows Desktop Releases (`v*.*.*`)
- Windows NSIS installer (`.exe`)
- `latest.yml` – Auto-update metadata
- `release.json` – Release information
- `.blockmap` – Differential update files

### Browser Extension Releases (`ext-v*.*.*` / `extension-latest`)
- Packaged Chrome and Edge browser extension (`memora27-extension.zip`)

### Source Code
The application source code is maintained in a separate private repository and is not publicly distributed here.
